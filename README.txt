TP N° 1 - Lenguaje IV
========================

Archivos:
- index.html
- style.css
- script.js

Cómo ejecutar:
1. Abrir la carpeta en Visual Studio Code.
2. Abrir index.html en el navegador.
   También puede usarse la extensión Live Server.
3. Completar:
   - Nombre Ubicación
   - Latitud
   - Longitud
4. Presionar "Abrir Ubicación".
5. Se abrirá Google Maps en una nueva pestaña con las coordenadas ingresadas.

Ejemplo para probar:
Nombre: Universidad Católica de Salta
Latitud: -24,7335
Longitud: -65,4095

Nota:
El programa acepta decimales escritos con coma o con punto.
